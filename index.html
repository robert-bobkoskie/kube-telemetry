About this Dashboard

This dashboard provides real-time health monitoring of the Demo Platform & Controller infrastructure across multiple sites. Data is collected via SSH from each host, evaluated against thresholds, and rendered as the tile statuses on the landing page. Each tile below shows the SSH commands used to gather its data.

Applications

SBI Controller Status
SBI controller pods + deployed version from ArgoCD. DOWN if any pod not Running/Completed. Shows version on tile.
kubectl get pods -n svc -o wide --no-headers
kubectl get application -n argocd -o custom-columns=NAME:.metadata.name,VERSION:.spec.source.targetRevision --no-headers
Filter: "sbi" in pod_name
ArgoCD
GitOps continuous delivery pods. DOWN if any pod not Running/Completed.
kubectl get pods -n argocd -o wide --no-headers
Controller NS Pod Status
All pods in the svc namespace. DOWN if any pod not Running/Completed.
kubectl get pods -n svc -o wide --no-headers
Controller Infra NS Pods
Infrastructure namespace pods on controller nodes. DOWN if any pod not Running/Completed.
kubectl get pods -n ctrl-infra -o wide --no-headers
Controller OLLY NS Pods
Observability namespace pods on controller nodes. DOWN if any pod not Running/Completed.
kubectl get pods -n ctrl-o11y -o wide --no-headers
Top Resource Pods
Top 30 pods ranked by CPU consumption across all namespaces. Identify resource-hungry workloads that may need limits tuned.
kubectl top pods --all-namespaces --no-headers

Health & Certs

Pod Health
Pods not in Running or Completed state. DOWN if >3 unhealthy pods.
kubectl get pods -n <namespace> -o wide --no-headers
Scans all discovered namespaces; Filter: status NOT in "Running", "Completed"
High Restart Pods
Pods with excessive restart counts. WARN if any >5 restarts, DOWN if >5 such pods.
kubectl get pods -n <namespace> -o wide --no-headers
Scans all discovered namespaces; Filter: restarts > 5
Platform K8S MGMT Certs
K3s management & cert-manager certificates on platform hosts. DOWN if expired, WARN if <60 days.
kubectl get certificates --all-namespaces -o custom-columns=NAMESPACE,NAME,READY,EXPIRY,RENEWAL,SECRET
sudo openssl x509 -in /var/lib/rancher/k3s/server/tls/*.crt -noout -enddate
Controller K8S MGMT Certs
K3s management & cert-manager certificates on controller hosts. DOWN if ready ≠ True.
kubectl get certificates --all-namespaces -o custom-columns=NAMESPACE,NAME,READY,EXPIRY,RENEWAL,SECRET
sudo openssl x509 -in /var/lib/rancher/k3s/server/tls/*.crt -noout -enddate
SBI MGMT Certs
TLS secrets in the svc namespace. DOWN if expired, WARN if <60 days.
kubectl get secrets -n svc --field-selector type=kubernetes.io/tls --no-headers
kubectl get secret <name> -n svc -o jsonpath='{.data.tls\.crt}' | base64 -d | openssl x509 -noout -enddate
Platform Ingress Certs
TLS secrets bound to Ingress resources + cluster TLS secrets. DOWN if expired, WARN if <60 days.
kubectl get ing -A -o json
kubectl get secrets -A --field-selector type=kubernetes.io/tls --no-headers
kubectl get secret <name> -n <ns> -o jsonpath='{.data.tls\.crt}' | base64 -d | openssl x509 -noout -enddate

Resources

CPU Utilization
Per-host CPU usage percentage. WARN >80%, DOWN >95%.
top -bn1 | grep 'Cpu(s)' | awk '{print $2 + $4}'
Memory Utilization
Per-host memory usage percentage. WARN >85%, DOWN >95%.
free -m | awk 'NR==2{printf "%s,%s,%s,%.1f", $2,$3,$4,($3/$2)*100}'
Disk Utilization
Root filesystem usage. WARN >85%, DOWN >95%.
df -h / | awk 'NR==2{print $3","$4","$5}'
Load Average
System load relative to CPU core count. WARN if 1-min load >8.
cat /proc/loadavg | awk '{print $1","$2","$3}'
K8s Node CPU
Per-node CPU utilization from Kubernetes metrics. WARN >80%, DOWN >95%.
kubectl top nodes --no-headers
K8s Node Memory
Per-node memory utilization from Kubernetes metrics. WARN >80%, DOWN >95%.
kubectl top nodes --no-headers

Architecture

🖥
Collector
Python + Paramiko SSH
Parallel workers per host
→
CSV Storage
Per-host timestamped CSVs
in RESULTS/ directory
→
Report Generator
Evaluates thresholds
Produces this HTML SPA

Collector version: metrics_collector — Supports Site-Beta, Site-Gamma, Site-Alpha sites.
Hosts are configured in hosts.yaml. SSH key auth with optional passphrase via .env file.
